# Architecture decision records

One file per decision, numbered and never renumbered. A record states the context, the
decision, and the consequences — including the ones we did not like. Superseded records stay
in place with a pointer to what replaced them; deleting them loses the reasoning, which is the
only reason to write them down.

Format: `NNNN-kebab-title.md`.
